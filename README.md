# 🎃 Halloween Pumpkin Catcher Game

Hey! So I made this cool Halloween game where you catch falling pumpkins. It's pretty fun and not too hard to play!

## What is this?

It's a simple browser game I built using p5.js (a JavaScript library that makes drawing stuff easier). You control a basket at the bottom and try to catch pumpkins falling from the top. Every time you catch one, your score goes up!

## How to Play

1. Just open the `halloween-game.html` file in any web browser (Chrome, Firefox, whatever you have)
2. Use the **Left Arrow** and **Right Arrow** keys to move your basket
3. Catch the pumpkins before they hit the ground
4. Try to get the highest score you can!

That's it! Super simple.

## What's Cool About It

- **Halloween vibes** - Dark purple background with orange pumpkins
- **Moving stars** - There are little stars in the background that move across the screen
- **The basket looks kinda real** - It's brown with an orange arc on top
- **Pumpkins have stems** - Small green rectangles on top to make them look more like actual pumpkins
- **No game over** - You can play forever, just keep catching!

## What I Learned

Making this taught me a bunch of stuff:
- How to use p5.js to draw shapes and make them move
- How keyboard controls work in JavaScript
- How to detect when two things touch each other (collision detection)
- How to make things loop and reset (like when the pumpkin goes off screen)

## The Code

Everything is in one HTML file - the styling, the JavaScript, everything. I used:
- **HTML/CSS** for the page layout and colors
- **p5.js library** for drawing the game
- **JavaScript** for all the game logic

The code has basic stuff like variables for position, functions that run every frame, and if-statements to check when you catch a pumpkin.

## Problems?

If it's not working:
- Make sure you have internet (it needs to load p5.js from a CDN)
- Try a different browser
- Check if JavaScript is enabled
